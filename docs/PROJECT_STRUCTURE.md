# Project Structure

- `assets/` CSS, JS and static images
- `config/` application and database configuration
- `database/` schema, view, procedure and trigger SQL
- `includes/` shared header, footer, authentication and sidebar
- `auth/` reserved authentication module area
- `user/` user dashboard and account modules
- `admin/` admin management area
- `uploads/` uploaded item images
- `docs/` viva and Git documentation
- root PHP files are public entry pages
